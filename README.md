# DATOS: The Data Engineering Pilipinas Conference

Website for DATOS, organized by [Data Engineering Pilipinas](https://dataengineering.ph/).
Preview: https://imjbmkz.github.io/datos_conference/ · Planned domain: `datos.dataengineering.ph`

The site is plain HTML, CSS and a little JavaScript, generated by a small Python script
from YAML content files. There is no framework to upgrade and no server to run.

## Run it locally

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python build.py --serve                             # http://localhost:8000
```

`python build.py` alone writes the site to `dist/`. If a content file has a mistake
(a missing field, an unknown speaker id, a photo that isn't there), the build stops
and tells you which file and entry to fix.

## Where things live

```
src/
  data/
    site.yaml                 # org info, nav, socials, current edition
    editions/2026/
      event.yaml              # date, venue, capacity, registration link, highlights
      sessions.yaml           # the agenda
      speakers.yaml           # people on the program (speakers, hosts, remarks)
      organizers.yaml         # organizing team on the About page
      sponsors.yaml           # sponsor tiers and logos
      faq.yaml
  templates/
    base.html                 # page shell: <head>, SEO, header, footer
    partials/                 # header.html, footer.html
    components/               # reusable building blocks (see below)
    pages/                    # one template per page
  static/
    css/tokens.css            # colors, type, spacing — change the look here
    css/site.css              # component styles
    js/site.js                # menu, countdown, speaker dialogs, "happening now"
    images/<year>/speakers/   # speaker photos
    images/<year>/organizers/ # organizer photos
    images/<year>/sponsors/   # sponsor logos
build.py
```

## Common edits

**Add or update a speaker.** Edit `speakers.yaml`. Put a square photo (600 px or larger)
in `src/static/images/2026/speakers/` and set `photo: their-name.jpg`.
Until a photo is added the card shows initials.

**Add someone to the organizing team.** Add a block to `organizers.yaml`; only `name` and
`role` are required. The About page picks it up on the next build:

```yaml
- name: "Juan dela Cruz"
  role: "Logistics"
  org: "Data Engineering Pilipinas"
  photo: "juan-dela-cruz.jpg"     # optional, in src/static/images/2026/organizers/
  links:
    linkedin: "https://www.linkedin.com/in/..."
```

Someone who is both an organizer and a speaker can reuse their speaker photo with
`photo: "images/2026/speakers/their-photo.jpg"`.

Any content file can be JSON instead of YAML (e.g. `organizers.json`); the build reads
whichever exists.

**Change the agenda.** Edit `sessions.yaml`. Times are 24-hour (`16:35`). People are
referenced by their `id` from `speakers.yaml`. Set `featured: true` to show a session in
"Agenda at a glance" on the home page.

**Add a sponsor.** Drop the logo (SVG or transparent PNG) in
`src/static/images/2026/sponsors/` and add it under a tier in `sponsors.yaml`.

**Open, close or waitlist registration.** In `event.yaml`, set `registration.status` to
`open`, `waitlist` or `closed`, and keep `registration.url` pointing at the Meetup event.

**Add the livestream.** Set `livestream.url` in `event.yaml`; the schedule and register
pages switch to a "Watch the livestream" button.

## Reusable components

| File | Macros |
| --- | --- |
| `components/ui.html` | `button`, `section_head`, `badge`, `event_meta`, `countdown`, `feature_card`, `stat`, `cta_banner`, `faq_list`, `map_embed`, `notice`, `pixels` |
| `components/people.html` | `avatar`, `speaker_card`, `speaker_dialog` |
| `components/agenda.html` | `agenda_item`, `agenda_timeline`, `agenda_glance` |
| `components/sponsors.html` | `logo_tile`, `logo_tiers` |
| `components/icons.html` | `icon` |

Components take data as arguments and contain no event-specific text, so new pages are
mostly a matter of arranging them.

## Next year's edition

1. Copy `src/data/editions/2026/` to `src/data/editions/2027/` and edit the files.
2. Add `src/static/images/2027/` for photos and logos, and an `og-2027.png` share image.
3. Set `current_edition: "2027"` in `site.yaml`.

## Deployment

`.github/workflows/deploy.yml` builds every pull request and publishes `main` to the
`gh-pages` branch, which GitHub Pages serves.

To switch to `datos.dataengineering.ph`:

1. Add a DNS `CNAME` record: `datos` → `imjbmkz.github.io`.
2. In **Settings → Secrets and variables → Actions → Variables**, add
   `BASE_PATH` = `/`, `SITE_URL` = `https://datos.dataengineering.ph`,
   `CNAME` = `datos.dataengineering.ph`.
3. Re-run the workflow, then set the custom domain and **Enforce HTTPS** in **Settings → Pages**.
